# Сайт «Услуги · Махачкала» — рабочая сборка (этап 3 конвейера «мясорубка»)

Готов к заливке на хостинг: раздать содержимое этой папки как корень домена.
Статический сайт — бэкенд не нужен, PHP не нужен, конструктор не нужен.

Проверен локально (headless-Chromium): мобильная 375 px и десктоп 1280 px,
все кнопки, форма, карта, скорость. Чек-лист — `/root/site-test-checklist.md`.

## 2. Что заменить владельцу перед публикацией

Искать по значению `XXXXXXXXXX` (телефон) и по классу `.ph` (красный пунктир в макете):

| Что | Где | Замена |
|---|---|---|
| Телефон | все страницы: `tel:+7XXXXXXXXXX`, `wa.me/7XXXXXXXXXX`, текст `+7 (XXX) XXX-XX-XX` | реальный номер |
| **Или в одном месте** | `assets/site.js` → `CONFIG.PHONE` и `CONFIG.WA` | подставится автоматически во все ссылки |
| Счётчик Метрики | `assets/site.js` → `CONFIG.METRIKA_ID` | номер счётчика (сейчас 0 = не подключён) |
| Пиксель VK | `assets/site.js` → `CONFIG.VK_PIXEL_ID` | id пикселя (advertising-plan.md, раздел 6.2) |
| Адрес, ориентир, режим работы | главная (блок «Где мы находимся»), подвал, `/politika`, `/oferta` | фактические данные |
| Карта | главная, iframe в блоке адреса — сейчас показывает Махачкалу | в `src` подставить `text=<адрес>&z=16` |
| Реквизиты ИП | подвал, `/politika`, `/oferta` | ИНН, ОГРНИП, ФИО |
| Цены-заполнители `.ph` | `uslugi` (тиражи печати, цветная печать) | прайс владельца |
| Домены | `assets/site.js` → `CONFIG.DOMAIN`; `sitemap.xml`; `.htaccess`; canonical в `<head>` | купленные домены |

## 3. Домены и короткие ссылки (marketing-brief.md, раздел 10.2–10.3)

- Основной: `uslugi-mahachkala.ru` (кандидат; финальную свободу проверять у регистратора).
- Короткий для QR: `mhk24.ru` — домен листовки. Оба домена могут смотреть
  на одну и ту же папку: тогда `/oktyabr`, `/sportiv`, `/kirovskiy` отрабатывают
  из `.htaccess` (Apache). Точка расклейки → 301 → главная с `utm_source=flyer`
  и своим `utm_campaign`.

**nginx** (если хостинг на nginx, вместо `.htaccess`):

```nginx
location = /oktyabr   { return 301 /?utm_source=flyer&utm_medium=offline&utm_campaign=oktyabrskiy&utm_content=a4_p1; }
location = /sportiv   { return 301 /?utm_source=flyer&utm_medium=offline&utm_campaign=sportivnyy&utm_content=a4_p1; }
location = /kirovskiy { return 301 /?utm_source=flyer&utm_medium=offline&utm_campaign=kirovskiy&utm_content=a4_p1; }
location / { try_files $uri $uri/ /index.html =404; }
```

Новая точка расклейки = одна строка в `.htaccess` (или в nginx) + новый SVG-QR
(см. `/root/qr/README.md`).

## 4. Яндекс.Метрика — что уже в коде и что настраивается в кабинете

В `assets/site.js` реализованы события (advertising-plan.md, раздел 6.1):

| Цель | Тип | Реализация |
|---|---|---|
| `zayavka_forma` (Ц1) | URL-цель | срабатывает на визите на `/spasibo/` — **создать в кабинете Метрики: тип «URL», условие «Равно» `/spasibo`** |
| `whatsapp_click` (Ц2) | JS-событие | клик по любой `wa.me` |
| `phone_click` (Ц3) | JS-событие | клик по `tel:` |
| `telegram_click` (Ц4) | JS-событие | клик по `t.me` |
| `catalog_view` (Ц5) | JS-событие | доскролл до каталога цен / якорного меню |
| `route_click` (Ц6) | JS-событие | «Проложить маршрут», ссылки на карты |
| `promo_qr10` (Ц7) | JS-событие | отправка формы с промокодом `QR10` |
| `prihod_qr` (Ц8) | по параметрам посетителя | визит с `utm_source=flyer`; если условия нет — отчёт «Источники → Метки» с фильтром |

В кабинете дополнительно: вебвизор (в коде `webvisor: true`), автоматическая
разметка ссылок Директа (`yclid`/`ysclid` не отключать), импорт целей
`zayavka_forma` и `whatsapp_click` в Директ. Пиксель VK — `CONFIG.VK_PIXEL_ID`.

## 5. Форма заявки — как работает доставка на статическом хостинге

Форма отправляет данные на `/spasibo/` (GET, без бэкенда). Там собирается
текст заявки и стоит одна кнопка **«Отправить заявку в WhatsApp»** — сообщение
с уже подставленной задачей, контактом, промокодом и UTM уходит владельцу.
Цель `zayavka_forma` срабатывает на сам визит на `/spasibo`, то есть даже без
кнопки WhatsApp заявка считается.

Если позже появится реальный обработчик (почта/CRM) — вписать endpoint в
`assets/site.js` (обработчик `submit` форм) и оставить `/spasibo` как
подтверждение. Чекбокс согласия на обработку ПД обязателен и уже стоит везде.

## 6. Скорость — что сделано для «до 3 сек»

- Шрифты самохостятся (`assets/fonts/*.woff2`, subset cyrillic+latin), `display=swap`.
- Внешних запросов нет ни одного (кроме карты Яндекса и, при подключении,
  Метрики) — Google Fonts убраны.
- Одна таблица стилей, один скрипт, картинок нет вовсе.
- Включены сжатие и кэширование (`.htaccess`).

Проверить после заливки: PageSpeed Insights / `curl -w '%{time_total}'`.
